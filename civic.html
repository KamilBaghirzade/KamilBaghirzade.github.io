Calgary civic data in MySQL

How can community, ward, and civic census files support queries in a relational database?

Current deliverable

A MySQL database built from Calgary civic datasets. The current milestone is to verify how the files can be joined and which questions the combined data can answer.

Current focus

The current work covers importing CSVs, examining table structure, and validating candidate join keys before combining data.
